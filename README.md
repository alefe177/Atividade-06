# GIT

O Git é um sistema de controle de versão gratuito e de codigo aberto, permitindo que vários desenvolvedores colaborem no mesmo projeto ao mesmo tempo.
Existem alguns conceitos tecnicos no git eles são: Repositorio, Branch, Commit e Merge
Repositório: O diretório ou pasta onde o projeto é armazenado.
Branch: Ramificações do código que permitem trabalhar em funcionalidades separadas da linha principal.
Commit: O ato de salvar o estado do projeto com uma descrição das alterações feitas.
Merge: O processo de fundir diferentes branches, unindo as alterações.


comandos do git:
git clone
git pull
git init
git add
git commit
git remote
git push
git branch
git merge



# GITHUB

O github  é a plataforma de hospedagem para os projetos que utilizam o GIT, seria como uma rede social para os programadores, podendo postar seus projetos sendo salvos na Nuvem,ele serve para armazenar, gerenciar e compartilhar projetos de software facilitando o trabalho em equipe
